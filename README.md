# Smooth Light

Fabric mod for Minecraft 1.21.1 that makes all light changes gradual instead of instant:

- breaking a light source — light fades out smoothly;
- placing a light source — light ramps up smoothly;
- covering a light source or an opening with a block — light dims smoothly (block light and skylight);
- opening a passage near a light source — light flows in smoothly.

No new blocks and no client/server desync: the mod tracks per-position transitions of light emission and opacity directly in the light engine on both sides.

# Smooth Light (RU)

Fabric-мод для Minecraft 1.21.1, который делает все изменения света плавными вместо мгновенных:

- сломал источник света — свет плавно гаснет;
- поставил источник света — свет плавно разгорается;
- закрыл источник света или проём блоком — свет плавно тускнеет (блочный и небесный свет);
- открыл проход рядом с источником — свет плавно «вливается».

Никаких новых блоков и рассинхрона клиент/сервер: мод ведёт по-позиционные переходы эмиссии и светопроницаемости прямо в движке света с обеих сторон.
